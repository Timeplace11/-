# Риски и эксплуатация

## Low-latency, надежность и деградация

### Edge-First архитектура
**Что на edge**:
- Детекция лиц (YOLO-Face)
- Оценка качества
- Liveness detection
- Извлечение эмбеддинга
- ANN поиск
- Решение о доступе

**Что в центре**:
- База сотрудников (master)
- Хранилище эмбеддингов (master)
- Обучение моделей
- Audit log (master)

### Сценарии деградации

| Сценарий | Действие | Восстановление |
|----------|----------|----------------|
| Offline сеть | Edge работает с локальным кешем | Синхронизация после восстановления |
| Недоступность модели | Использовать предыдущую версию | Автоматический rollback |
| Поломка edge | Переключить на соседнюю проходную | Замена оборудования |
| Перегрузка GPU | Снизить разрешение | Добавление ресурсов |

### Время достижения 1 секунды
- Детекция: 50ms (YOLO-Face)
- Качество: 20ms (правила)
- Liveness: 100ms (CNN)
- Embedding: 80ms (ArcFace)
- ANN поиск: 50ms (Faiss)
- Decision: 10ms (правила)
- Команда турникету: 100ms
- **Итого**: 410ms (укладываемся!)

### Идемпотентность
- Команда турникету: по event_id
- Retry: не более 3 раз
- Exponential backoff: 100ms, 200ms, 400ms

### Offline логирование
- Логи хранятся локально до 1M событий
- При восстановлении: batch upload
- Приоритет: сначала критичные события

## Privacy, safety и governance

### Биометрические данные
**Что считается биометрией**:
- Изображение лица (только во время обработки)
- Эмбеддинги (512-dim vector)

**Что НЕ хранится**:
- Исходные изображения (удаляются после обработки)
- Ключевые точки лица

### Хранение
- Эмбеддинги: зашифрованы (AES-256)
- Ключи шифрования: отдельно (HSM)
- Срок хранения: пока сотрудник активен + 30 дней
- Удаление: по истечении срока, по запросу

### Доступ
- RBAC (Role-Based Access Control)
- Администраторы: полный доступ к логам
- Операторы: только мониторинг
- Охрана: только UI ручной проверки

### Удаление сотрудника
1. Увольнение → отметка в HR системе
2. Синхронизация → edge узлы (в течение 15 минут)
3. Удаление эмбеддинга из центра
4. Edge кеш: удаление при следующей синхронизации

### Audit log
- Все решения логируются
- Причина решения (score, quality, liveness)
- Ручные вмешательства (кто, когда, решение)
- Хранение: 7 лет

### Юридические требования
- **152-ФЗ**: согласие на обработку биометрии
- **GDPR**: право на забвение
- Сбор согласий: при приеме на работу

## Отказ в доступе

### Как объяснить сотруднику
"Уважаемый сотрудник! Система не смогла вас идентифицировать. Причины могут быть:
- Низкое качество изображения
- Плохое освещение
- Изменение внешности
Пожалуйста, обратитесь к охране."

### Безопасность информации
- Никакой информации о других сотрудниках
- Никаких деталей о внутреннем решении
- Не раскрывать пороги системы

## Что нельзя запускать без проверки

1. **Биометрическая система**: юридическая проверка (152-ФЗ, GDPR)
2. **Сбор данных**: согласие сотрудников
3. **Безопасность**: пентест, аудит кода
4. **Операционная процедура**: инструкции для охраны
5. **Тестирование**: пилот на добровольцах
