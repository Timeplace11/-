# Self-Review

## Самое слабое место
Liveness detection использует упрощенный подход, основанный на анализе изображения, без 3D depth mapping. Это может быть недостаточно для защиты от качественных видео-атак.

## Допущения
1. Хорошие условия освещения на проходных (базовые)
2. Сотрудники сотрудничают с системой (не прячут лица)
3. Сеть стабильна в обычном режиме
4. Охрана адекватно реагирует на manual review

## Нерешенные риски
1. Может быть атака на ANN индекс (poisoning)
2. Система может не справиться с близнецами
3. Не учтены сценарии смены внешности (операции, возраст)

## Компромиссы для demo
1. Использована одна камера вместо двух
2. Упрощенная liveness
3. Локальная база сотрудников
4. Нет UI охраны

## Стоп-критерии для пилота
1. FAR > 0.1% → остановить (безопасность)
2. FRR > 5% → остановить (юзабилити)
3. >10 жалоб от сотрудников → остановить
4. Любой инцидент безопасности → немедленная остановка
