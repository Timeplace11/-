# Использование AI-инструментов

## Инструменты
- Deepseek для архитектурного проектирования, для написания кода PoC

## Роль AI

### Помощь AI
1. **Декомпозиция задачи**: разбил сложную систему на компоненты
2. **Архитектура**: предложил гибридную edge-cloud модель
3. **Выбор моделей**: рекомендация YOLO-Face, ArcFace, Faiss
4. **Структура документации**: шаблоны для product.md, architecture.md
5. **Расчеты**: помог с экономическими вычислениями

### Отклоненные предложения
1. **Использовать cloud-only**: отклонил (задержка, безопасность)
2. **Хранить лица в центральной БД**: отклонил (privacy)
3. **Использовать LLM для принятия решений**: отклонил (недетерминизм)
4. **Full CNN end-to-end**: отклонил (сложность обучения)

### Ошибки AI
1. **Неправильный формат эмбеддингов**: предложил использовать 128-dim → исправил на 512-dim
2. **Не учел offline режим**: дополнил архитектуру локальным кешем
3. **Слишком оптимистичные FAR/FRR**: скорректировал до реалистичных значений
4. **Предложил хранить raw images**: отклонил по privacy причинам

## Проверка безопасности
1. Все предложения AI проверял на соответствие принципам privacy
2. Каждый компонент анализировал на предмет утечек данных
3. Добавил шифрование и audit log
4. Исключил решения, потенциально нарушающие 152-ФЗ

## Самостоятельные решения
1. Выбор порогов allow/deny/manual_review
2. Архитектура edge-first
3. Использование ANN вместо полного перебора
4. Стратегия деградации при сбоях
5. План раскатки MVP
