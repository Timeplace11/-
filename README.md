# -# Face Access Control System
## Система распознавания лиц для контроля доступа в офисном кампусе

### 📌 О проекте
Система автоматического распознавания лиц для проходных офисного кампуса, заменяющая карты-пропуска. Цель — ускорить проход сотрудников, снизить нагрузку на охрану и повысить безопасность.

### 🎯 Бизнес-ценность
- **Сотрудники**: проход без карты, время ожидания сокращается с 90 до <10 секунд в пик
- **Охрана**: снижение ручных проверок с 40 до <5 случаев в день
- **Бизнес**: экономия ~2.5 млн ₽/год на времени сотрудников и работе охраны

### 🏗️ Архитектура (кратко)
- **Edge (проходная)**: детекция лиц, оценка качества, liveness, извлечение эмбеддингов, поиск в локальном ANN-индексе
- **Центр**: управление базой сотрудников, обучение/обновление моделей, аудит, мониторинг
- **Гибридная модель**: быстрый путь на edge, сложные случаи отправляются в центр или на ручную проверку
